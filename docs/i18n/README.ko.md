## 소개

자체 호스팅 결제 게이트웨이와 모바일 콘솔입니다. 판매자가 청구서를 만들면 고객이 온체인으로 결제하고, 게이트웨이가 체인을 감시해 청구서를 정산합니다. 계정도, 수탁도, 토큰 발행도 없습니다.

- **멀티체인 수금** — Ethereum, Base, Arbitrum, Polygon, BNB Chain, 그리고 공개 인덱서를 통한 BTC·TRON 감시
- **온체인 정산** — `PaymentHub` 컨트랙트는 판매자 주소로만 자금을 해제하며, 재전송 방지 서명이 포함된 정산 증명을 사용합니다
- **크로스체인 인텐트** — source / confirm / credit / done 상태를 명시한 원장, 자동 재시도 없음, 모든 단계 대사
- **안전장치** — 청구서 발행 전 제재 목록 심사, 다중 RPC 장애 조치와 회로 차단, 재편성(reorg)을 고려한 최종성
- **모바일 앱** — 네이티브 안드로이드 셸 3종(개발/테스트/공개), iOS는 PWA로 설치
- **국제화** — 제품 UI 5개 언어(zh, en, de, fr, es), 저장소 문서 9개 언어

## 규제 경계

비수탁 소프트웨어만 제공합니다: 수탁, 법정화폐 입출금, 토큰 발행, 자체 브리지 없음. EU MiCA 기준으로 이는 소프트웨어 제공이며 CASP 서비스가 아닙니다. 수탁·환전·법정화폐 교환을 추가하면 개인이 취득할 수 없는 CASP 라이선스가 필요합니다. [COMPLIANCE.md](../COMPLIANCE.md).
