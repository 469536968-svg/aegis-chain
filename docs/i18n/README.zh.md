## 这套系统是什么

自托管的收款网关 + 手机端控制台。商户开一张收款单，客户在链上付款，网关监听链上到账并结算这张单。没有注册账号、没有托管钱包、也不发币。

- **多链收款**：以太坊、Base、Arbitrum、Polygon、BNB Chain，另通过公开索引器监听 BTC 与 TRON
- **链上结算**：`PaymentHub` 合约只把资金释放到商户自己的地址，结算凭据带防重放签名
- **跨链意图**：台账带明确状态机（source / confirm / credit / done），不自动重试，每一跳都要对账
- **安全机制**：开单前制裁名单筛查、多 RPC 故障转移与熔断、按确认数与重组风险判定最终性
- **手机 App**：原生安卓壳（开发版 / 测试版 / 公开版三个包），iOS 走 PWA 安装
- **国际化**：产品界面 5 种语言（中、英、德、法、西），本仓库文档 9 种

## 合规边界

只做非托管软件：不托管资产、不做法币出入金、不发代币、不自建跨链桥。按欧盟 MiCA，这属于软件提供而非 CASP 服务；一旦加上代客保管、兑换或法币兑换，就落入 CASP 牌照范围，个人拿不到。详见 [COMPLIANCE.md](../COMPLIANCE.md)。
