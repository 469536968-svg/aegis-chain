# Aegis Chain (العربية)

> منصة قبول مدفوعات متعددة السلاسل غير احتجازية: تبقى المفاتيح الخاصة لدى التاجر، ولا تتولى المنصة سوى الفواتير والتسويات ودفتر نوايا العبور بين السلاسل.

## ما هذه المنصة

بوابة دفع ذاتية الاستضافة مع لوحة تحكم على الهاتف. ينشئ التاجر فاتورة، ويدفع العميل على السلسلة، وتراقب البوابة السلسلة ثم تُسوّي الفاتورة. لا حسابات ولا احتجاز ولا إصدار رموز.

- **قبول متعدد السلاسل** — Ethereum وBase وArbitrum وPolygon وBNB Chain، إضافة إلى مراقبة BTC وTRON عبر مفهرسات عامة
- **تسوية على السلسلة** — عقد `PaymentHub` لا يحرر الأموال إلا إلى عنوان التاجر نفسه، مع إثبات تسوية موقّع ومقاوم للإعادة
- **نوايا العبور بين السلاسل** — دفتر بحالات صريحة (source / confirm / credit / done)، دون إعادة محاولة آلية، وكل خطوة تُسوّى
- **ضمانات** — فحص قوائم العقوبات قبل إصدار الفاتورة، وتعدد RPC مع قاطع دائرة، ونهائية تراعي إعادة التنظيم
- **تطبيق الهاتف** — غلاف أندرويد أصلي بثلاث بنيات (dev / test / prod)؛ ويعمل iOS كتطبيق PWA
- **التعريب** — واجهة المنتج بخمس لغات (zh, en, de, fr, es)، ووثائق المستودع بتسع لغات

## ما هو متاح للعموم

| مفتوح | مغلق |
| --- | --- |
| الوثائق، ملخص المعمارية، ملاحظات الامتثال، سياسة الأمن، خارطة الطريق | شيفرة محرك الدفع، وماسحات السلاسل، ومصدر عقد التسوية وسكربتات النشر |
| متتبع المشكلات، تصحيح الترجمات، تقارير الأخطاء في السلوك الموثّق | مفاتيح التوقيع، وعناوين الإنتاج، ومجموعات العناوين، وإعدادات التجار |

هذا المستودع واجهة عامة للمعلومات والدعم، والتطبيق الأساسي **ليس مفتوح المصدر** — راجع [OPEN-SCOPE.md](../OPEN-SCOPE.md).

## حد الامتثال

برمجيات غير احتجازية فقط: بلا احتجاز، بلا تحويل نقدي ورقم/رقمي، بلا رمز، وبلا جسر خاص. وفق MiCA الأوروبية هذا تقديم برمجيات وليس خدمة CASP؛ وإضافة الاحتجاز أو التبادل أو التحويل النقدي تستلزم ترخيص CASP لا يستطيع فرد الحصول عليه. راجع [COMPLIANCE.md](../COMPLIANCE.md).
