## 概要

セルフホスト型の決済ゲートウェイとモバイルコンソールです。加盟店が請求書を作成し、顧客がオンチェーンで支払い、ゲートウェイがチェーンを監視して請求書を決済します。アカウントなし、カストディなし、トークン発行なし。

- **マルチチェーン入金** — Ethereum、Base、Arbitrum、Polygon、BNB Chain、および公開インデクサ経由の BTC・TRON 監視
- **オンチェーン決済** — `PaymentHub` コントラクトは加盟店自身のアドレスにのみ資金を解放し、リプレイ防止署名付きの決済証明を使います
- **クロスチェーン・インテント** — source / confirm / credit / done の明示的状態を持つ台帳。自動リトライなし、各ホップを照合
- **安全機構** — 請求書発行前の制裁リスト照合、複数 RPC のフェイルオーバーとサーキットブレーカ、reorg を考慮した確定性
- **モバイルアプリ** — ネイティブ Android シェル 3 種（開発／テスト／公開）、iOS は PWA で導入
- **国際化** — 製品 UI は 5 言語（zh, en, de, fr, es）、本リポジトリの文書は 9 言語

## コンプライアンス境界

非カストディのソフトウェアのみ：資産預託、法定通貨の入出金、トークン発行、自前ブリッジは行いません。EU の MiCA ではこれはソフトウェア提供であり CASP サービスではありません。カストディ・交換・法定通貨兌換を加えると、個人では取得できない CASP ライセンスが必要になります。[COMPLIANCE.md](../COMPLIANCE.md)。
