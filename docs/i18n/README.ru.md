## Что это

Самостоятельно размещаемый платёжный шлюз и мобильная консоль. Продавец выставляет счёт, клиент платит в сети, шлюз отслеживает цепочку и закрывает счёт. Без аккаунтов, без кастоди, без выпуска токена.

- **Мультичейн-приём** — Ethereum, Base, Arbitrum, Polygon, BNB Chain, а также наблюдение за BTC и TRON через публичные индексаторы
- **Расчёт в сети** — контракт `PaymentHub` переводит средства только на адрес продавца, с подписанным доказательством расчёта и защитой от повторного воспроизведения
- **Кросс-чейн-намерения** — реестр с явными состояниями (source / confirm / credit / done), без автоматических повторов, каждый шаг сверяется
- **Защитные механизмы** — проверка санкционных списков до выставления счёта, отказоустойчивость нескольких RPC с предохранителем, финальность с учётом реорганизаций
- **Мобильное приложение** — нативная оболочка Android в трёх сборках (dev / test / prod); iOS ставится как PWA
- **Локализация** — интерфейс на пяти языках (zh, en, de, fr, es), документация репозитория на девяти

## Что открыто

| Открыто | Закрыто |
| --- | --- |
| Документация, обзор архитектуры, заметки о соответствии, политика безопасности, дорожная карта | Код платёжного движка, сканеры сетей, исходники расчётного контракта и скрипты деплоя |
| Трекер задач, правки переводов, отчёты об ошибках документированного поведения | Ключи подписи, продакшн-эндпоинты, пулы адресов, конфигурация продавцов |

Репозиторий — публичная площадка для информации и поддержки. Основная реализация **не является открытым исходным кодом** — см. [OPEN-SCOPE.md](../OPEN-SCOPE.md).

## Границы соответствия

Только некастодиальное ПО: без хранения средств, без ввода/вывода фиата, без токена, без собственного бриджа. По MiCA (ЕС) это предоставление ПО, а не услуга CASP; добавление кастоди, обмена или конвертации фиата потребует лицензии CASP, которую частное лицо получить не может. См. [COMPLIANCE.md](../COMPLIANCE.md).
