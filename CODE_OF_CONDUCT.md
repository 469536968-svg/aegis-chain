# Code of Conduct

## Our pledge

We want participation in this project to be harassment-free for everyone, regardless of age, body size, disability, ethnicity, gender identity or expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be direct about code, generous about people. Critique the change, not the contributor.
- Assume the other person is acting in good faith until shown otherwise.
- Accept that maintainers may decline a change for scope or compliance reasons; the reason will be stated.
- Never post private keys, seed phrases, API keys, merchant addresses or customer data in an issue, PR or chat.

## Unacceptable behaviour

- Insults, sexualised language or imagery, deliberate intimidation, doxxing, or sustained disruption.
- Discriminatory jokes or slurs, or political/religious campaigning unrelated to the project.
- Publishing someone's private information without permission.
- Asking contributors to bypass the non-custodial boundary, to handle customer funds, or to publish closed-source material.

## Scope

Applies to issues, pull requests, discussions and any project channel, and to anyone representing the project in public.

## Enforcement

Report incidents to the maintainer through GitHub (open a private security advisory if the report is sensitive). Reports are handled confidentially. Consequences range from a warning to a permanent ban, decided by the maintainer.

This is a condensed adaptation of the Contributor Covenant, version 2.1.
