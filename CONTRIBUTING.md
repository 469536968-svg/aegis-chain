# Contributing

This repository accepts contributions to **documentation, translations and issue reports**. It does not accept
pull requests against the core implementation, which lives elsewhere and is proprietary.

## Welcome

- **Translation fixes** — including the nine README languages (zh, en, fr, ko, ja, ru, id, es, ar). Fix wording,
  keep the technical claims identical; do not soften the compliance boundary.
- **Documentation bugs** — a step that does not work, a broken link, an outdated version number.
- **Integration questions** — open an issue describing your chain, your backend and what you need from the API.
- **Bug reports on documented behaviour** — what you expected, what happened, which network.

## Not accepted

- Patches to the payment engine, scanners or contract (no source here by design).
- Requests for custody, fiat ramps, token issuance or a bridge.
- Re-hosting or forking the docs under the project name or logo — see `LICENSE`.

## Style

- Issues in any of the nine documented languages are fine; English or Chinese gets the fastest reply.
- One issue, one topic. Include version and chain.
- Never paste private keys, seed phrases, API keys or merchant addresses in an issue.

## Security

Anything exploitable goes to GitHub Security Advisories, not the issue tracker — see `SECURITY.md`.
