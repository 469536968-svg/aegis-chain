# demo/ — 手机演示（纯前端，MIT）

`index.html` 是**单文件、零依赖**的演示：双击即可打开，不需要网关、不需要钱包、不发任何网络请求。数据只在浏览器内存里。

能演示的完整链路：

1. 新建收款单（选链、币种、金额）
2. 生成收款地址
3. 点「模拟到账」→ 确认中 → 已到账
4. 切换语言（当前只有 zh / en，其余语种是 `i18n` 标签下的待办）

## 这**不是**什么

- 不是真实收款，链上不会发生任何转账
- 不是网关本身，真实监听 / 结算 / 跨链对账不在本仓库
- 不是托管钱包，演示页不生成、不保存私钥

## 改它

纯 HTML + 内联 CSS/JS，一个文件放所有东西，方便手机离线打开。修改后请自测：

- 三种手机宽度（320 / 390 / 430）下按钮不换行错位
- 语言切换后无缺词（缺词会回退成 key）
- 刷新页面后状态重置（这是预期，不是 bug）
